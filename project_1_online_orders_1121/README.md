# ☕ Онлайн-система заказов для кафе «11/21 Кофе»

## 🎯 Цель
Создать онлайн-канал заказов с самовывозом, чтобы снизить нагрузку на персонал и повысить удобство для клиентов.

## 🔍 Контекст
- Формат: кафе, специализация — завтраки и бизнес-ланчи  
- Проблема AS-IS: телефонные заказы, ошибки, очереди  
- Решение TO-BE: онлайн-меню, заказ, уведомления о готовности, история заказов

## 🧩 Роль аналитика
Анализ AS-IS, моделирование TO-BE, формализация требований, описание Use Case, создание глоссария и wireframe.

## 📈 Эффект
- Сокращение ошибок и времени обслуживания  
- Повышение удобства клиентов  
- Основа для интеграции с доставкой
